# Material model decisions

Optional worker-maintained note for source conflicts, consequential assumptions
or compatibility choices. The parent establishes the governing authority; this
record captures its decision, not permission to choose one. Use an existing
specification when sufficient, omit unused prompts and avoid routine edit logs.

## Decision: descriptive title

- **Question and alternatives:** the material ambiguity and likely consequences.
- **Evidence:** useful source locations, model/code observations or user decisions.
- **Interpretation:** the selected behavior, or explicit uncertainty while unresolved.
- **Authority and rationale:** who or what controls the choice and why it applies.
- **Affected behavior:** actual modules, parameters, observables, experiments or
  documentation that must agree with it.
- **Checks and limits:** evidence needed to verify the change, residual uncertainty
  and any interpretation this decision supersedes.

Repeat only for another material decision. Link to a [source map](source_map.md)
or the corresponding existing specification where useful; adapt that link to
the project's actual record instead of copying the same evidence into both.
