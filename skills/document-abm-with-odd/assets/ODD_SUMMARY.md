# ODD summary

Optional summary for an audience needing a concise model account. The documenter
adapts these prompts and the link to the full [ODD document](ODD.md); remove
unused prompts and keep material assumptions and limits. This summary is derived
from the full description and does not replace it or silently correct it.

## Purpose and scope

Identify the full ODD and model revision, intended use, entities, state, temporal
and spatial scales, and ODD 2020 or material ODD+D scope. Label proposed, partial
or stale source documentation so readers understand the summary's limits.

## Core behavior

Explain process order, interactions, randomness, initialization, time-varying
inputs, major submodels, observables and stopping at the audience's needed
level. Link consequential details back to the full ODD; retain relevant
geographic assumptions instead of simplifying them into a different model.

## Evidence, unknowns and limitations

Name the evidence used and preserve material unknowns, discrepancies,
assumptions and geographic or scientific limitations. Distinguish intended
behavior, actual implementation and observed results. A concise description
adds no evidence of scientific validity.
