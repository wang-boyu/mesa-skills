# ODD evidence gaps

Optional record for substantial missing or conflicting evidence. In writable
work, the documenter adapts it in an assigned documentation path. In audit-only
work, reviewers return findings in their response; the parent may adapt this
record only in a separately authorized external report. Neither a recorded gap
nor a suggested correction authorizes changing the protected target.

| Affected ODD element and claim | Missing or conflicting evidence and locator | Consequence | Evidence or authority needed | Responsible owner and disposition |
|---|---|---|---|---|

Keep only material gaps. Identify unavailable evidence, inspected defects and
preferences accurately; do not equate them. The parent records accepted,
rejected, deferred or unresolved findings with reasons. When resolved, retain
the governing evidence and affected recheck rather than deleting an inconvenient
finding. Use prose beside an ODD element when simpler; no fixed identifiers,
status vocabulary or separate file are required.
